# Lonebrew Tap

This repository contains Formulae and Casks to be used with Homebrew: https://brew.sh

Tap this repository
```sh
brew tap lonebrew/apps
```

## List of apps

### Casks

xattr -dr com.apple.quarantine /Applications/YouTube\ Music.app
